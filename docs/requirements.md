# MSR Requirements Analysis

## User Stories

1. As a PhD student, I want to find software engineering data sources so that I know where to get research data
2. As a researcher, I want to learn about data collection methods so that I know how to collect data.
3. As a researcher, I want to learn about analysis methods so that I know how to analyze research data.
4. As a PhD student, I want to find conferences and journals so that I know where to publish my research.
5. As a researcher, I want a simple interface where I can easily switch between sections so that I can find information quickly.
