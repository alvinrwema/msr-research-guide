## About the Project

The MSR Research Guide is a site designed to help Mining Software Repositories (MSR) researchers with their research. The website will basically have four main sections: Data Sources, Collection Methods, Analysis Methods, and Publication Venues. Each of these sections will provide detailed information to help users learn about these different parts of MSR research.

## Completed Milestone
